# Assignment page simplification, v1.20

Approved by the owner on October 14, 2026: replace the existing crowded Assignment history rows with a simple compact table.

- Default to current assignments. Full history remains available as a separate toggle.
- Show a small summary for current ownership, fresh-view assignments, and total history.
- Support search by lead, owner, source, assigner, or reason, plus an owner filter.
- Show lead, owner, assigner, assignment time, access mode, reason, and an Open lead action.
- Paginate at 50 rows so large assignment sets remain usable.
- On small screens, reuse the existing responsive table-to-card behavior.

This is a presentation and navigation change only. It does not change assignment permissions, ownership, history, visibility modes, CRM data, or routing behavior.
