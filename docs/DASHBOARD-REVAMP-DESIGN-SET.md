# Elevanta AI — Dashboard Revamp Design Set

Status: Visual reference set — selected direction 1

This design set supports [DASHBOARD-ROLE-SCREEN-SPEC-v1.0.md](../DASHBOARD-ROLE-SCREEN-SPEC-v1.0.md). It is the visual target for the next implementation. The design files use safe illustrative data only and must not be treated as real CRM reporting.

## Theme parity rule

Each dark/light pair has the same role purpose, layout, information hierarchy, navigation, filters, cards, queues, charts, labels, actions, and recognition areas. Only visual tokens change: background, surface color, text contrast, border/shadow treatment, and theme-appropriate chart colors.

## Implementation constraints

- Use only cards, charts, queues, actions, and recognition concepts approved in the role screen specification.
- Keep agents’ recognition private and benchmarks anonymized.
- Do not add a lead score, combined performance score, prediction, or universal source-mixed ranking.
- Treat all visible mock values, names, and dates as illustrative.
- Test dark/light parity for every role before release.
